# Сценарии в Richi

[English](SCENARIOS.md) | Русский

Сценарии превращают повторяемую многошаговую работу агентов — ревью веток,
нагрузочное и регрессионное тестирование, отчёты, разбор инцидентов — в
структурированные процедуры с памятью Richi и проверкой отчётов этапов.

## Как устроен этап M1

1. **Исполняет агент в чате, состояние и проверки держит Richi.** Richi сам не
   запускает команды и не поднимает агентов. Агент начинает запуск
   (`scenario run`), берёт этапы по одному (`scenario next --claim`), выполняет
   их в своей песочнице и отчитывается (`scenario report`).
2. **Универсальные кубики.** Формат v1 описывает типизированные поля ввода
   (`string`, `text`, `number`, `boolean`, `select`, `multiselect`, `secret`),
   явный граф зависимостей (`needs`), условия (`if`), ограниченные матрицы (до
   50 экземпляров с безопасными для shell ключами `<step>.<idx>`), выбор навыка
   под каждого агента и проверки отчётов (`outputs`, `data_required`,
   `min_items`, `exit_code`, `file_exists`, `evidence_git`).
3. **Безопасные шаблоны.** Подстановки `{{путь | фильтр}}` и условия
   разбираются без `eval`. Каждое выражение внутри `command.params.command`
   обязано заканчиваться фильтром `| shell` (`shlex.quote`). Секретные поля
   допускаются только в параметрах выполнения агента и проверках наличия в
   условиях и никогда не сохраняются в SQLite.
4. **Записи запусков и общий журнал.** Каждый запуск создаёт запись `task` с
   тегом `scenario-run` (обновляется на ключевых переходах) и пишет все правки
   и события запусков в `scenario_events` (`scenario log`).
5. **Встроенный шаблон Review.** В пакет входит синтетический шаблон `review`
   (`memory.brief` → параллельные углы `skill` → сведение `instruction` → шлюз
   человека `gate`), доступный сразу или копируемый командой `scenario copy`.
6. **Визуальная вкладка «Сценарии» в `richi map`.** Откройте `richi map` и
   перейдите на вкладку **Сценарии**: каталог определений и встроенных шаблонов,
   визуальный конструктор пайплайнов (перетаскивание шагов и соединение портов
   `needs` на графе или переупорядочивание в списке, инспектор всех 8 типов
   шагов с выбором скиллов и шаблонных переменных, прямое сохранение по ключу
   карты или команда `richi scenario apply`), просмотр запусков с переходом к
   задаче на карте (ожидающие вопросы человеку в UI только для чтения с
   копируемой командой `richi scenario answer` для чата) и общий журнал событий.

## Быстрый пример

```sh
richi migrate
richi scenario plan review --input branch=feature_x
richi --project-path /path/to/service scenario run review --input branch=feature_x
richi --project-path /path/to/service scenario next run-review-20261127-0001 --claim
```

Полный контракт команд для агентов см. в
[SCENARIOS.ru.md](../skills/richi/references/SCENARIOS.ru.md).

## План развития

- **M1 (этот этап)**: формат v1, безопасные шаблоны, хранение на уровне
  workspace и проекта, таблицы запусков схемы 4, планировщик, аренда этапов,
  проверка отчётов, записи запусков, общий журнал, встроенный шаблон `review`,
  CLI и документация EN/RU.
- **M2**: хуки жизненного цикла агентов (`SessionStart`, `Stop`, `PreCompact`)
  со счётчиком продолжений на стороне Richi.
- **M3**: память процесса (`compare` с baseline прошлых запусков,
  `memory.record`, прошлые находки в `memory.brief`).
- **M4 (включён)**: вкладка «Сценарии» в `richi map` (каталог определений,
  визуальный конструктор с перетаскиванием и соединением портов + режим списка,
  инспектор шагов, просмотр запусков с переходом на карту и командами ответа
  на вопросы, общий журнал).
- **M5–M9**: пресеты и галерея, экспорт и импорт в репозиторий с доверием по
  хэшу, свободный холст в стиле Blueprints поверх того же графа, ретроспективы,
  передача этапов между агентами, развилки и триггеры.
