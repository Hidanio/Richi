# Каталог инструментов

[English](TOOLS.md) | Русский

Вкладка **«Инструменты»** находится рядом с картой и энциклопедией. Откройте
инструмент, чтобы прочитать его назначение и практические инструкции, выберите
проект, затем просмотрите только задачи с сохранённым свидетельством применения
этого инструмента. Повторяемые сценарии без задачи показаны отдельно. Одна
связь с проектом не прикрепляет к инструменту все задачи проекта.

Каталог загружает короткие описания и количество проектов/применений. Полные
инструкции, источники и связанные задачи появляются при выборе инструмента;
незагруженное количество задач не означает отсутствия задач.

Инструментами могут быть линтеры, профилировщики, тестовые клиенты и внутренние
утилиты. Один сценарий может объединять несколько инструментов и проектов.
Карточка инструмента содержит общие инструкции, сценарий — настройки в
конкретном контексте, датированный эксперимент или исследование — отдельную
попытку и её результат. Самостоятельно полезные определения остаются в
энциклопедии.

Каталог использует общую SQLite-базу, источники и историю. Сущностям `tool`
нужна схема 3. Для существующей базы нужны явные backup и миграция; чтение
каталога и переключение runtime никогда не мигрируют её автоматически.
Подробнее — [граф и миграция](../skills/project-memory/references/GRAPH.ru.md).

Полные команды CLI и процедура заполнения для агента —
[«Инструменты и их применение»](../skills/project-memory/references/TOOLS.ru.md).
Там описаны направления связей, область применения, исторические результаты
и защита от конфликтов. Автоматического импорта из репозиториев, задач или
другого workspace нет.
