# Агенты и их скиллы

[English](AGENT_SKILLS.md) | Русский

Постоянное правило может называть скилл. Агенты могут читать одни и те же папки.
У каждого свои правила поиска и именования скиллов, поэтому Richi показывает,
какие скиллы доступны каждому агенту на этом компьютере. Правило называет один
скилл для всех агентов или свой для каждого (см. [RULES.ru.md](RULES.ru.md)), а
`rules show` отдаёт каждому агенту его скилл.

Richi задаёт источники скиллов для своих **встроенных** агентов Claude Code,
Codex, Cursor и Antigravity. Пользователь может **подстроить** встроенного агента, выключив
источник или добавив папки со скиллами. Он также может **описать ещё одного
агента**, указав его имя, папки скиллов и признак, по которому его
узнать. Эти настройки принадлежат пользователю и общие для всех workspace на этом
компьютере; они не являются знаниями и не копируются вместе с workspace.

## Посмотри агентов

```sh
richi --compact-json skill-sources list
```

В `agents` перечислены все агенты по порядку: `id` (используется в `--skill ID=NAME`
и `rules show --agent ID`), `name`, `builtin`, `detected` (агент выглядит
установленным у этого пользователя), `skills` (сколько скиллов ему доступно) и
`sources`. Для агентов, которых умеет подключать установленный launcher,
он сообщает `detected`. Если старый launcher ещё не умеет подключать встроенного
агента (например, Cursor или Antigravity), поле `connection` равно null. Тогда
Richi определяет наличие агента по его собственным встроенным источникам и
возвращает null, если все эти источники отключены.
Для агента, добавленного пользователем, Richi проверяет включённые папки скиллов и
возвращает null, если все они выключены. У источника есть `key`, путь `path`, признак `exists` (папка есть; `denied`,
если у пользователя нет к ней доступа; у выключенного источника ни то ни другое не
проверяется), `enabled` (источник включён), `added` (папку добавил пользователь) и
число скиллов `skills`. `chat_prefix` говорит, называются ли чаты агента `ID:…` в
`RICHI_CHAT_ID`, по чему Richi тоже узнаёт агента. Хук Cursor передаёт
`--chat cursor:<id>`. Antigravity передаёт `ANTIGRAVITY_CONVERSATION_ID`, который
Richi использует как `antigravity:<id>`. У Codex идентификатор чата совпадает с ID треда.
`updated_at` — версия настроек пользователя для агента; null, если их нет.
`presets` перечисляет известных агентов, которых можно добавить, с папкой, которую
читает каждый. `problem` заполнено, когда файл настроек не удаётся использовать, а
`problem_code` говорит почему: `damaged` (файл повреждён: исправьте или удалите его),
`unreadable` (его не удалось прочитать в этот раз), `newer` (его записала более
новая версия Richi: обновите Richi; эта версия его не меняет) или `large` (он
больше, чем читает эта версия: обновите Richi, если его записала более новая, иначе
уменьшите файл; эта версия его не меняет). Тогда Richi работает
только со встроенными агентами, без настроек пользователя. Изменение, после которого
файл стал бы больше, чем Richi читает, отклоняется. `unknown_agents` перечисляет
настройки, которые эта версия хранит как есть, но не использует: агента, встроенного
только в более новый Richi, или настройки одного агента, которые она не может
использовать (`error` говорит почему: их записала более новая версия, они повреждены
или своих агентов больше, чем использует эта версия, — она оставляет описанных
раньше). `next`, если есть, — команда, которая их удаляет; настройки остальных
агентов продолжают работать. Список называет первые 20, а `unknown_agents_more`
считает остальные; ключ длиннее 200 символов, какой бывает только от ручной правки,
обрезается и получает длину и хеш.

## Опиши ещё одного агента

```sh
richi --compact-json skill-sources add gemini-cli --name "Gemini CLI" \
  --skills ~/.gemini/skills --variable GEMINI_CLI=1
```

Добавляй агента только по просьбе пользователя. ID — от 1 до 32 строчных латинских
букв, цифр или `-`, начинается с буквы и потом не меняется. `--skills` — папка, где
каждый скилл лежит в своей подпапке с файлом `SKILL.md`; укажи абсолютный путь или
путь от `~`, а для нескольких папок повтори параметр. `--variable NAME` или
`NAME=VALUE` называет переменную окружения, которую задают оболочки агента, чтобы
`rules show` узнавал агента; без неё агент передаёт `--agent ID`, или его
идентификатор чата начинается с `ID:`. Процесс, запущенный из терминала другого
агента, несёт переменные обоих агентов, а иногда и чужой идентификатор чата; когда
признаки указывают на разных агентов, Richi не называет ни одного, и агент передаёт
`--agent ID`. `--manual-skills front-matter` исключает
скиллы, у которых в `SKILL.md` указано `disable-model-invocation: true`: правило не
может заставить агента взять скилл, который вызывает только пользователь.

Свою интеграцию (`richi setup`) Richi ставит только встроенным агентам. Для другого
агента пользователь сам добавляет шаг `richi rules show --agent ID` в постоянные
инструкции этого агента.

## Подстрой агента

Antigravity читает скиллы пользователя из `~/.gemini/config/skills`, встроенные
скиллы из `~/.gemini/antigravity/builtin/skills` (либо `antigravity-ide`,
`antigravity-cli` или `$ANTIGRAVITY_APP_DATA_DIR/builtin/skills`) и включённые
плагины из `~/.gemini/config/plugins`. В `SKILL.md` обязателен заголовок YAML
frontmatter. Дополнительные пути из `skills.json` и `plugins.json`
автоматически не читаются; папки со скиллами можно добавить через
`skill-sources update antigravity --add-skills FOLDER`.

Cursor читает скиллы из `~/.cursor/skills`, `~/.agents/skills`, `~/.claude/skills`
и `~/.codex/skills`. Встроенные скиллы Cursor находятся в `~/.cursor/skills-cursor`.
Codex читает личные скиллы из `~/.agents/skills` и каталога `skills` своего
профиля. Оба клиента находят скиллы во вложенных каталогах. Codex переходит
по ссылкам на каталоги и ожидает обычный файл `SKILL.md`.
Richi также рекурсивно проверяет папки, добавленные пользователем для этих
агентов. Для каждого источника Richi проверяет
до 100 000 записей в каталогах. Если у источника есть признак `truncated`,
фактическое число скиллов может быть больше указанного.

Если в прежней версии уже был настроен свой агент
`cursor` или `antigravity`, после обновления Richi использует встроенное имя и встроенные
правила распознавания агента и отбора скиллов. Добавленные папки остаются в
списке. Выключенная папка остаётся выключенной, даже если теперь это встроенный
источник. Включить её можно по ключу из `skill-sources list`. При обновлении
Richi сохраняет исходный файл настроек. Вернуть настройки по умолчанию можно
командой сброса, описанной ниже.

```sh
richi --compact-json skill-sources update claude --disable claude-app --add-skills ~/work/team-skills
richi --compact-json skill-sources update gemini-cli \
  --expected-updated-at 2026-01-02T03:04:05.000000Z --name "Gemini" --manual-skills front-matter
```

`--disable SOURCE` и `--enable SOURCE` принимают `key` источника из `skill-sources list` или
добавленную папку. `--add-skills` и `--remove-skills` меняют добавленные папки. У
своего агента `--name`, `--variable` (пустое значение убирает переменную) и
`--manual-skills` меняют его описание; встроенный агент их не принимает. Передавай
`updated_at` агента в `--expected-updated-at`; опусти параметр, если значение null,
то есть встроенного агента ещё никто не подстраивал. Более новая версия — это
конфликт, и ничего не записывается: прочитай список снова.

## Удали агента или его настройки

```sh
richi --compact-json skill-sources remove gemini-cli --expected-updated-at 2026-01-02T03:04:05.000000Z
```

У своего агента команда удаляет его описание; правила, которые называют для него
скилл, сохраняют это имя. У встроенного агента она убирает изменения пользователя и
возвращает агента таким, каким его определяет Richi. Папки скиллов на диске
никогда не затрагиваются.

## Агенты в карте

Вкладка карты **«Агенты»** показывает тот же список: источники скиллов каждого
агента с папками и числом скиллов, признаки, по которым Richi узнаёт агента, и
правила, которые дают ему скилл, с пометкой, если такого скилла у агента нет.
Страница, открытая командой `richi map`, переключает источники, добавляет папки и
агентов и сразу сохраняет изменения; любая другая страница вместо записи собирает
команду `richi skill-sources`.
