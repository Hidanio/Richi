# Использование Richi

[English](LICENSING.md) | Русский

По [лицензии Richi Community Use License версии 2.0](LICENSE.md) люди и
организации могут пользоваться Richi бесплатно. Письменное согласие нужно для
коммерческого использования самого Richi и внедрения во всей компании.

## Примеры

| Как вы используете Richi | Условия |
| --- | --- |
| Ведёте личный проект, в том числе если вы работаете в компании | Бесплатно |
| Как консультант готовите с помощью Richi отчёт, за который платит клиент | Бесплатно |
| Проводите внутренний пилот, пользуетесь общей установкой в команде или внедряете Richi в отделе | Бесплатно |
| Используете Richi для некоммерческих задач НКО, учебного заведения или госучреждения | Бесплатно |
| Публикуете некоммерческий форк или открываете pull request | Бесплатно |
| Пользуетесь Richi при разработке программы, которую продаёте | Бесплатно |
| Включаете Richi в поставку этой программы или даёте клиентам доступ к поиску Richi в платном портале | Нужно письменное согласие заранее |
| Продаёте сам Richi или платный доступ к его размещённой копии | Нужно письменное согласие заранее |
| Все пять сотрудников студии самостоятельно выбрали Richi для работы | Бесплатно |
| Студия решила внедрить Richi для всех пятерых и начинает с двух сотрудников | Нужно письменное согласие до первого этапа внедрения |

## Как получить разрешение

Напишите [Ричардасу Кучинскасу](mailto:hidanjkezor@gmail.com) и коротко опишите,
как хотите использовать Richi в коммерческих целях или внедрять его во всей
компании. Начинать можно после получения письменного согласия на такое использование.

## Данные и результаты работы

Для ваших данных, записей, кода проектов и результатов работы действуют их
собственные условия. Если результат включает фрагмент Richi или стороннего
материала, к этому фрагменту применяются его условия.

## Сторонний код и прежние версии

У стороннего кода остаётся своя лицензия. Для прежних версий Richi и ранее
полученных разрешений действуют условия, на которых они были предоставлены.
